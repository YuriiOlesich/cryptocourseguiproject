МОДУЛЬ 01

Шифр Цезаря

Моноалфавітний зсув в українському алфавіті з 33 літер.

n = 33
РЕЗУЛЬТАТ
СОЗФКЬ БУКМ БУКМСДЙЬ
Алгоритм та формули

Шифрування: Cᵢ = (Pᵢ + k) mod 33. Розшифрування: Pᵢ = (Cᵢ − k) mod 33. Пробіли та розділові знаки зберігаються.

МОДУЛЬ 02

Квадрат Віженера ROT2

Кожен рядок квадрата зміщується на дві позиції; ключ циклічно повторюється.

ROT2 · n = 33
РЕЗУЛЬТАТ
КТШКЄБ РЙЄР РЙЄРЄШЕБ
Алгоритм та формули

Для шифрування: Cᵢ = (Pᵢ + 2·Kᵢ) mod 33. Для розшифрування: Pᵢ = (Cᵢ − 2·Kᵢ) mod 33. Пробіли не зсувають позицію ключа.

Квадрат Віженера ROT2 (33×33)
