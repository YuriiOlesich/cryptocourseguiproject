КРИПТОЛОГІЯ — вебзастосунок до завдання 5

Запуск:
1. Розпакуйте архів.
2. Відкрийте index.html у сучасному браузері (Chrome, Edge, Firefox).
3. Інтернет для роботи алгоритмів не потрібен; Google Fonts — лише необов'язкове оформлення.

Функції:
- Цезар: український алфавіт із 33 літер, довільний цілий зсув, шифрування/розшифрування.
- Віженер ROT2: формула C=(P+2K) mod 33, ключ повторюється лише на літерах, квадрат 33×33.
- Полібій: таблиця 6×6, пробіл=64, крапка=65, кома=66.
- RSA: варіант 21 (p=88471, q=11491, d=578421283), BigInt modular exponentiation, режим M mod N або блоки по 5 цифр.
